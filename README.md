# BrandLens AI 🔍

### AI-Powered Brand Governance & Content Compliance Platform

BrandLens AI is a Streamlit-based platform designed to help businesses maintain consistent brand communication by analyzing written content against predefined brand guidelines.

## 🚀 Features

- **Content Analysis:** Detects potential brand guideline violations.
- **Compliance Scoring:** Provides a compliance score for submitted content.
- **Smart Suggestions:** Generates improved content suggestions.
- **Brand Profiles:** Supports brand-specific tone, approved words, prohibited words, and writing rules.
- **Review History:** Stores previous content reviews.
- **Analytics Dashboard:** Displays review statistics and performance insights.

## 🛠️ Technology Stack

- Python
- Streamlit
- Scikit-learn
- TF-IDF and Cosine Similarity
- SQLite

## 💻 Run Locally

1. Clone the repository:

   `git clone https://github.com/Vaibhavrajput326/BrandLens-AI.git`

2. Open the project folder:

   `cd BrandLens-AI`

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`

## 📁 Project Structure

- `app.py` — Streamlit application interface
- `engine.py` — Content analysis and correction logic
- `database.py` — SQLite database operations
- `requirements.txt` — Project dependencies

## 🎯 Objective

To help organizations improve brand consistency, identify content guideline violations, and create clear, trustworthy communication.
